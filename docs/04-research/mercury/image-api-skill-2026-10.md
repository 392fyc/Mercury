# 通用图像 API 技能

`packs/core/skills/image-api/` 给没有原生生图能力的宿主提供一个小型生成和参考图编辑入口。Codex 普通生图仍使用原生工具；用户明确选择 API 或要求验证此工具时，才走付费接口。技能没有扩展到其他 API 用途。

技能只负责读取获准的本地输入、调用官方 Images 端点、记录原图与用量。项目继续拥有视觉锚点、尺寸和透明要求、后处理、独立审查及素材准入规则。候选不会由脚本写进生产目录。两种宿主入口由 core pack 安装，不依赖额外 MCP 服务或 SDK。

凭据通过明确的私有文件或环境变量引用；配置、账本和原始产物留在主 checkout 的 Git 忽略目录。所有工作树共用这一位置。SQLite 将预算检查和预留合为一笔事务，请求失败或收费未知时继续占用预留；不自动重试。预留不是服务端绝对扣费上限，超出预留会阻止后续调用。共享账号中未经过该账本的消费，仍须由负责人另外核对和分配预算。

工具固定支持两种 GPT Image 2.5 模型及其已核对快照，每次一张 PNG，提供有限尺寸和质量档。接口、计费依据与可运行的占位配置在技能的 `references/usage.md`；费率变动或加入新模型必须重新核对一手文档。离线测试覆盖预算竞争、未知收费、参考图字节与安全错误输出，实测和独立复审的私有证据不进入本页。
