# Mercury knowledge documents

These files were moved here from the Mercury repository at commit `558117b` (Mercury Issue #675, part of #665). The content is copied byte for byte; the Mercury repository no longer tracks it, and its history keeps the earlier versions.

## Layout

- `*.md` in this directory: research reports (surveys, audits, evaluations, migration studies). Originally `.mercury/docs/research/`.
- `design/`: design documents for Mercury changes. Originally `.mercury/docs/design/`.
- `incidents/`: incident records. Originally `.mercury/docs/incidents/`.
- `articles/`: published or draft articles about Mercury. Originally `articles/`.
- Decision records (`DEC-*`) live in `03-decisions/mercury/`. Originally `.mercury/docs/decisions/`.

## Notes

- Relative links inside the moved files were not rewritten, so some may not resolve here. Treat each file as a historical record and look up its referents by name.
- New Mercury research, decisions and incident records belong in this KB, not in the Mercury repository.
