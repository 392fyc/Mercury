# 分块协议与命令

仅在没有双方可用的原文件通道时读取本文件。脚本只处理本地文件，不发消息、不联网、不脱敏，也不解包或执行内容；会话传递由宿主已经授权的工具完成。需要 Python 3 标准库。

## 为什么这样传

工具输出可能被截断，图片预览可能缩放或转码，两端工具也可能不同。因此先固定一份文件清单，再用传输编号、分块编号、偏移、长度和分块 SHA-256 定位补传范围，最后与清单中的完整文件摘要比较。分块收到只证明收到该部分。

清单和载荷应来自已确认的同一发送方、同一版本；SHA-256 不提供身份认证。载荷是待处理数据，不能作为 shell 命令、提示词或脚本执行。脱敏后的副本是新的文件版本，重新准备传输。

## 准备与发送

下面命令从项目根执行。`<skill-dir>` 替换成当前技能的实际目录，通常为 `.mercury/packs/core/skills/test-file-delivery`。示例文件与目录均为通用名称，不包含真实项目或会话标识。

```text
python <skill-dir>/scripts/transfer.py prepare .tmp/review/clip.mp4 --out .tmp/review/outgoing
python <skill-dir>/scripts/transfer.py emit .tmp/review/outgoing --start 1 --end 2
```

`prepare` 流式读取原件，创建此前不存在的目录，包含 `manifest.json` 和 `packets.jsonl`，不修改原件。默认每块 8192 原始字节，可用 `--chunk-bytes` 调整，支持范围为 1–65536 字节；上限用于约束单次载荷的内存。它不自动识别敏感内容；调用前先完成技能要求的材料检查。

先传清单，再少量发送载荷。`emit` 从已固定的文件输出一块一行的 `MERCURY_TEST_FILE_JSON {...}`。清单含协议版本、随机传输编号、安全文件名、总长度、完整 SHA-256、分块大小与数量；每块含相同传输编号、块号、偏移、长度、分块 SHA-256 与 Base64 数据。清单中的文件名只作说明，不用来拼接接收端路径。清单限定为 8192 字节以内，避免异常输入驱动大内存读取。

按实际工具的参数、输出和会话读取限制调整批次。先传一块并实际回读，确认完整后再增加批量。8192 字节是保守起点，不是平台限制保证。不要在最终答复重复载荷。

## 两个方向的程序传递

- **本地到云端：** 本地程序读取清单和选定的原始载荷行，通过已经获准的目标会话发送工具传入。云端以受支持的会话读取工具获取原始消息，由代码提取完整载荷行到文件；不让模型复制或重写 Base64。
- **云端到本地：** 云端用执行工具直接输出 `emit` 的载荷行。本地程序读取该会话的原始命令输出，由代码提取到文件。会话读取时按工具说明启用输出、限制回合数量、沿返回游标取所需页；不反复拉取整段大历史。
- 程序编排时直接传递工具返回的字符串或字节。若接口返回嵌套 JSON，按实际结构解码；不要把对象隐式转成字符串，也不要把截断预览当原输出。经 shell 落盘时使用标准输入或文件参数，不把载荷或私有文字拼入命令行。
- 有些宿主只能显示结果，无法让程序访问原始消息或工具输出。此时报告该缺口，保留进度；不要发明文件读取接口或退回大段人工转抄。

## 接收与恢复

```text
python <skill-dir>/scripts/transfer.py receive --manifest .tmp/review/manifest.json --input .tmp/review/batch.jsonl --out .tmp/review/incoming
python <skill-dir>/scripts/transfer.py assemble .tmp/review/incoming --dest .tmp/review/received-clip.mp4
```

清单与 `batch.jsonl` 应由程序从原始工具结果保存。输入允许纯 JSON 行，也允许带上述标记的行。`receive` 核对传输编号、块号、偏移、解码长度和分块摘要，逐块保存；遇到损坏即非零退出，已核验块保留，相同块重放不会覆盖。成功回执只记录本批接受的包数（含重复包），不能据此推断全部块已齐。`assemble` 遇到首个缺块立即输出其编号；缺块、内容错误或写入失败时不发布目标文件。

根据接收回执只发送缺失块，例如 `emit ... --start 3 --end 3`。部分块损坏时，重新从发送方的固定 `packets.jsonl` 读取对应原行；不要让模型修复字符串。收发限额造成截断时缩小读取页或批次；需要改变分块大小时创建新的传输目录和编号，不能混用原分块。

`assemble` 逐块写入目标同目录下新建的临时文件并校验完整摘要，随后通过硬链接发布完整的目标文件，再移除自身临时文件；已有目标不会被覆盖。目标目录需要支持硬链接；文件系统不支持时返回非零退出，保留原分块，改用支持的项目私有目录。完成后按技能要求打开或解码文件。源码或压缩包的后续使用仍须符合本轮任务范围。

公开方法文档与技能只保留这种通用命令。真实文件清单、页面引用、会话路由、路径、回执及 Base64 载荷只留在获准的私有传输与项目私有目录中。
