# Mercury harness file ownership

Mercury is the sole source of truth for these generated paths in a downstream
repository:

- `.codex/agents/mercury-*`
- `.codex/rules/mercury-*`
- `.codex/project/mercury-*`
- `.codex/mercury-template.lock`

The Ship of Theseus (SoT) repository must not edit these files or independently
initiate changes to their contents. A requested change to a Mercury-owned file
must be made in Mercury's `.mercury/templates/codex-project/` source and then
published through Mercury's approved process. The lock is generated by the
synchronizer and must never be edited by hand.

Each downstream repository owns its domain-specific skills, configuration,
and workflows. Those files remain outside this template and are maintained by
that repository. This ownership boundary does not add new generated paths;
only destinations listed in `manifest.json` are managed by the synchronizer.
