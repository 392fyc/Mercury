# 有界深度研究

1. 列出需要回答的问题和研究范围；按任务需要设定合理的时间或来源边界。
2. 优先查找能直接支持结论的一手资料。记录来源链接，区分来源原文、基于来源的推断和相互冲突的说法。
3. 逐项标记问题为已回答、部分回答或 UNVERIFIED。解释未核实原因，不用猜测填补证据缺口。
4. 证据足以回答问题或达到本次设定的边界时停止。保留重要分歧和未决问题，不为通过指标而无限重试。

交付简明结论、问题覆盖情况、关键来源和仍存在的不确定性。研究过程不强制使用代理、固定搜索次数或多层编排；除非用户明确要求，不写入长期记忆或知识库。只使用当前会话实际提供的研究工具。
