# API 生图与参考图编辑

把已授权的图像需求转成候选文件，记录来源、参数与费用。适合 Claude 等没有原生生图工具的宿主；Codex 普通生图沿用原生工具，用户明确选择 API 或要求验证本工具时才使用这里的付费路径。

## 范围与输入

- 只处理本次授权的生成或编辑任务。技能可用不等于获准消费、购买素材、上传第三方图片、扩大预算或把候选导入生产目录。沿用现有用户授权，不为已获准步骤重复询问。
- 生成和编辑由具有写入权限的执行者完成。只读审查角色只检查输入、脚本和已有结果；Mercury 的 Claude 只读角色防护会拦截本工具，不能为生图关闭或绕过它。
- 读取项目现行视觉规则和已批准素材。先查看编辑目标和参考图，分清哪些内容须保留、哪些可以改变；记录其字节摘要。参考图只能来自获准向该服务递交的材料。
- 提示词写明用途、主体、材质、构图、预期显示尺寸、修改目标与保持项。精确布局、数值、交互状态、拼接和动画仍由项目的确定性工具与验收流程处理；生成图不能证明这些要求成立。

## 使用工具

读取[配置、费用和命令](references/usage.md)，在项目主 checkout 的 Git 忽略目录中准备配置和任务卡。

```text
python -B <skill-dir>/scripts/image_api.py --config <private-config.json> --card <card.json>
python -B <skill-dir>/scripts/image_api.py --config <private-config.json> --card <card.json> --execute
```

第一条只做离线输入检查，不读取 key、不创建账本、不联网。第二条才发送一次付费请求。`generate` 为文生图；`edit` 接受现有图片和提示词，可用于局部修改或带参考图的新候选。每次只输出一张 PNG，不自动重试，不自动切换模型、端点或供应商。

凭据只通过明确配置的 `key_file` 或 `key_env` 读取，不让模型转抄，不把 key 写进任务卡、配置、命令参数、日志、回执或 Git。`key_file` 指向用户批准的既有本地文件，无须复制它；不要默认读取宿主认证文件或继承别的项目的凭据授权。云端需要生成时，先确认该环境已有获准凭据通道，不为方便传输本机 key。

## 预算与结果

- 预算和预留额由本次授权范围确定；同一项目的所有 worktree 使用主 checkout 的同一份配置与 SQLite 账本。同一额度池中的不同项目需分配互不重叠的预算，或统一使用一个获准的项目根与账本；这份本地账本看不到其他工具的消费。
- 请求前原子预留费用并检查调用次数。响应含完整用量时按固定的已核对费率结算；超时、崩溃或用量不完整时继续保留预留额。不得删账本、换目录或自动重试来绕过限制。实际费用超过预留后工具停止后续调用，交由负责人核对。
- 预留是本地消费控制，**不是服务端绝对扣费上限**。只在额度、价格、质量和尺寸已核对的范围内使用；提高预算或加入新模型前核对官方资料与用户授权。
- 工具在私有状态目录的每次请求子目录中保存 `image.png` 与 `receipt.json`。核对能完整解码、真实尺寸与透明通道，再按项目规格做派生和目检；不把请求成功写成视觉批准。后处理保留原图并记录参数，不能默认套用某个项目的限色或像素化方式。
- 汇报生成/编辑是否成功、候选文件、参考图与结果摘要、实际费用或仍占用的预留额，以及未通过或未做的检查。独立审查、自身目检、用户视觉批准和素材准入分别记录。
- 原始图片、完整提示词卡、凭据引用和原始回执保留在项目私有目录。公开 Issue、PR、技能示例只写可公开的汇总；不发布账号、主机、绝对本机路径、私有图片或未经检查的 API 错误正文。跨环境交付沿用获准的私有文件通道。
