# 有界实现与核验

普通实现请求按任务本身处理；只有用户明确要求或既定计划规定此流程时才使用本技能。

## 流程

1. 对照用户要求和仓库约定，明确目标、允许改动的路径与验收条件；仓库要求时关联已有 Issue。
2. Astra 主代理负责范围、决策和整合，Luna Max 执行有界实现。另用独立上下文核对验收条件、关键差异和检查证据；不依赖 Claude Code 角色文件。若当前环境无法提供独立核验，说明这一限制。
3. 保留无关改动，只修改任务所需内容，并运行与风险相称的最小项目原生检查。
4. 未满足验收条件或发现范围问题时，报告具体缺口；不自动扩大任务或无限迭代。
5. 返回改动路径、逐项验收证据、检查结果和未解决限制。

本流程本身不会自动提交、推送、创建 PR、修改远程 Issue 或清理工作目录。需要这些动作时，依据当前任务和会话中已有授权，并遵守仓库规则。
