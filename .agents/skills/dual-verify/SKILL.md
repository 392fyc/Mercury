# 双上下文审查

本技能是可选审查方式，不是每次提交或创建 PR 的默认门槛。

## 审查

- 使用两个互不共享中间结论的独立上下文检查同一份基线、改动和验收条件。在 Mercury 的角色配置中，两者均使用 Luna Max。
- 给两者不同重点，例如一侧检查需求、逻辑与回归，另一侧检查边界、错误处理与仓库约定。无需设置不同推理强度，也无需固定工具调用格式。
- 要求审查者报告有证据支持的具体问题，标明文件位置、影响和不确定之处；没有发现问题时也应明确说明。
- 主代理合并重复项，核对分歧并复查关键证据。审查报告不自动授权修改或对外操作。

双路审查本身不等于仓库的 review 标记或审批。遵守仓库的受保护分支、必需审查与检查规则；不得绕过保护或直接写入受保护分支。
