# 一手资料核验

只核实会影响当前结论或实现的外部事实。

## 核验方式

- 优先查产品维护方的官方文档、发行说明和更新记录；包名、版本与发布状态以官方注册表为准。官方仓库可作补充。
- 记录能直接支持关键结论的来源链接，以及页面显示的版本或日期。区分资料明确说明的内容与基于资料的推断。
- 上游源码本身不能证明某版本已发布，也不能单独证明实际运行行为。
- 来源缺失、冲突或无法访问时，将相关说法标为 UNVERIFIED，并简述原因；不要编造链接或声称已验证。
- 证据足以支持本任务的决定后即可停止。列出仍未解决的问题；不设固定搜索次数或机械通过门槛。

## 结果

将来源放在相关结论旁，说明证据适用的版本或时间范围。
